# StayPrimePH User Guide

This guide is for guests, hosts, and admins who need simple help using StayPrimePH. Every step includes a link to the place where the user should go.

If you are testing locally, open the app at `http://localhost:3000` first, then use the same paths shown in the links below.

## Fast Help

1. For urgent account, booking, listing, or payment help, open the [Help Center](/support/help-center).
2. To send a message to the admin support team, sign in and use [Support live chat](/support/help-center).
3. To call support, use [0956 673 9577](tel:+639566739577).
4. To email support, send your concern to [support@stayprimeph.com](mailto:support@stayprimeph.com).

## Getting Started

1. Open the [StayPrimePH home page](/) to start browsing or choose a main action.
2. Create a guest account from [Guest registration](/register?role=guest) if you want to book stays.
3. Create a host account from [Host registration](/register/host) if you want to list a property.
4. Sign in from [Guest login](/login?role=guest) when you are booking or managing trips.
5. Sign in from [Host login](/login?role=host) when you are managing listings, calendar, or payouts.
6. If you forgot your password, start recovery from [Forgot password](/forgot-password).
7. If the app asks you to verify email, go to [Email verification](/verify-email) and follow the instructions sent to your inbox.

## Searching For A Stay

1. Start from [Search stays](/search) to browse all available homes.
2. Use the location field on [Search stays](/search) to enter a city, barangay, or nearby place.
3. Add dates and guest count from [Search stays](/search) so prices and availability are easier to compare.
4. Use filters on [Search stays](/search) when you need a certain property type, price range, bedroom count, or amenity.
5. On mobile, use the map/list switch inside [Search stays](/search) to move between map view and result cards.
6. If no stays appear, clear filters from [Search stays](/search) and search again with fewer requirements.

## Reading A Listing

1. Open a listing from [Search stays](/search) by selecting a stay card.
2. Check photos and gallery from [Search stays](/search) before continuing to the listing page.
3. Review amenities, house rules, guest capacity, and location details from the listing you opened through [Search stays](/search).
4. Use the booking panel on the listing you opened from [Search stays](/search) to choose dates, guests, and available packages.
5. If you have questions before booking, use the message option from the listing or go to [Guest messages](/guest/messages).
6. If a listing looks unsafe or misleading, contact [Support live chat](/support/help-center) before booking.

## Booking A Stay

1. Choose a stay and dates from [Search stays](/search).
2. Open the booking panel on the listing you selected from [Search stays](/search).
3. Review trip dates, guests, package access, house rules, and total price on the checkout screen reached from [Search stays](/search).
4. If the app asks you to sign in, use [Guest login](/login?role=guest) because host and admin accounts cannot create guest bookings.
5. If the date is unavailable, return to [Search stays](/search) and choose a different date or listing.
6. After requesting a booking, track its status from [My Bookings](/guest/bookings).
7. Open a booking from [My Bookings](/guest/bookings) to view details, cancellation options, and payment instructions.
8. For booking changes or active trip concerns, contact [Support live chat](/support/help-center).

## Payments

1. Check payment status from [My Bookings](/guest/bookings) after your booking request is created.
2. If online payments are disabled, read the payment note shown in [My Bookings](/guest/bookings) before sending money outside the app.
3. If online payments are enabled, use the payment action shown inside [My Bookings](/guest/bookings).
4. If a payment receipt or payment status looks wrong, contact [Support live chat](/support/help-center).
5. If you are a host checking payouts, open [Payout Settings](/host/payouts).
6. If you are an admin reviewing payments, open [Admin payments](/admin/payments).

## Becoming A Host

1. If you are new to hosting, start from [Become a host](/register/host).
2. If you already have a guest account, upgrade from [Become a host upgrade](/become-a-host/upgrade).
3. Start the listing wizard from [Host listing setup](/become-a-host/setup).
4. Add the property address from [Host listing setup](/become-a-host/setup) so the map and location details are correct.
5. Choose property type, privacy type, guest count, bedrooms, beds, and bathrooms from [Host listing setup](/become-a-host/setup).
6. Add amenities, at least 5 photos, title, description, and optional video or virtual tour from [Host listing setup](/become-a-host/setup).
7. Choose booking settings, pricing, discounts, safety details, and final host details from [Host listing setup](/become-a-host/setup).
8. Review and publish the listing from [Host listing setup](/become-a-host/setup); it may need admin approval before guests can see it.
9. After publishing, check status from [My Listings](/host/listings).

## Listing Problems Hosts Often See

1. If the listing will not publish, return to [Host listing setup](/become-a-host/setup) and complete the missing step shown by the wizard.
2. If photos will not upload, return to [Host listing setup](/become-a-host/setup) and try smaller clear images, then contact [Support live chat](/support/help-center).
3. If guests cannot book a date, open [Calendar Availability](/host/calendar) and check whether that date is blocked.
4. If your listing is not visible to guests, open [My Listings](/host/listings) and check whether it is still pending approval.
5. If pricing looks wrong, open [My Listings](/host/listings) or [Host listing setup](/become-a-host/setup) and review base prices, weekend prices, packages, and discounts.
6. If payout details are missing, open [Payout Settings](/host/payouts).

## Troubleshooting

1. If you cannot log in, use [Forgot password](/forgot-password) and then try [Guest login](/login?role=guest) or [Host login](/login?role=host).
2. If you are in the wrong dashboard, sign in again from [Guest login](/login?role=guest) or [Host login](/login?role=host) with the correct role.
3. If email verification is blocking you, open [Email verification](/verify-email) and check your inbox for the newest verification email.
4. If search has no results, open [Search stays](/search), clear filters, and try a wider location or fewer requirements.
5. If a booking date is unavailable, open [Search stays](/search) and choose different dates.
6. If a booking is missing, open [My Bookings](/guest/bookings) and confirm you are signed in with the same guest account used to book.
7. If host booking requests are missing, open [Booking Requests](/host/bookings) and confirm you are signed in as the listing host.
8. If notifications are not enough to explain what happened, open [Support live chat](/support/help-center) and send the booking ID, listing name, date, and screenshot if available.
9. If the app seems down, check [Service status](/status).
10. If you need privacy help, email [privacy@stayprimeph.com](mailto:privacy@stayprimeph.com).

## What To Include When Contacting Support

1. For booking issues, open [My Bookings](/guest/bookings) and include the booking, stay name, dates, and what changed.
2. For listing issues, open [My Listings](/host/listings) and include the listing name, status, and what you expected to happen.
3. For payment issues, open [My Bookings](/guest/bookings), [Payout Settings](/host/payouts), or [Admin payments](/admin/payments) and include the payment status shown.
4. For account access issues, open [Login and security](/account-settings/login-and-security) if you can sign in, or use [Forgot password](/forgot-password) if you cannot.
5. For urgent safety concerns, open [Support live chat](/support/help-center) and contact local emergency services when there is immediate danger.
